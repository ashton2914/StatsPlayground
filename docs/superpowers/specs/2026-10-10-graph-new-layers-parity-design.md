# Graph Builder-new 点图与线图设置设计

日期：2026-10-10
工作树：`261-graph-zoom-ux`
设计基线：`5df942c`
状态：待书面设计审阅

## 目标与范围

新版 Layers 的点图和线图采用旧 Graph Builder 的独立卡片、设置顺序、选项和默认值。每个设置实际影响绘图，能保存到项目并在重新打开后恢复。点图与线图可以单独使用，也可以同时显示；修改其中一个图层不改变另一个图层的设置。

继续使用新版 Rust/wgpu 渲染、数据缓存、Overlay 和相机流程。此次不增加 Bar、Smoother、Fit Line 等其他图形元素，不扩展右侧 STYLE 功能，也不修改旧版的统计算法。

## 现状与选择

- 旧版 `GraphBuilderView.tsx` 的 `PointsOptions` 有 5 项设置，`LineOptions` 有 8 项设置；绘图语义主要位于 `graphCore/transform.ts` 和 `graphCore/jitter.ts`。
- 新版通过全局 `rawMode` 表示点、线或点线组合，通过 `showMean` 额外叠加均值线。当前卡片共享 Mean 控件，其余设置为占位按钮，无法表达独立图层配置。
- 新版文档有 v1/v2 两种格式，尚无独立图层列表。前后端请求也没有汇总统计、误差区间、抖动和线图设置。

采用“复用旧版设置定义与界面，扩展新版图层契约和原生几何生成”的方案。仅增加界面无法兑现设置行为；切回旧版 ECharts 会改变新版的大数据、缓存和相机路径，因此不采用这两种方案。

## 使用体验

卡片标题采用旧版的图标、Scatter/Line 名称、2D 标签和删除按钮。保留新版左侧 Layers 所在位置，复用旧版的表单行、下拉框和滑块样式、翻译及选项顺序。

新建图形默认只有 Scatter。添加 Line 时保留 Scatter，Line 使用旧版默认设置；删除任一图层不修改其余图层。允许删除最后一个图层，此时绘图区显示添加图层提示。添加入口采用旧版的 `+` 选择体验，未实现的其他元素维持现有不可用状态。

常规新建图形最多一个 Scatter 和一个 Line，重复添加不会重置已有设置。旧文档迁移需要额外均值线时可以保留第二个独立 Line 卡片；每个卡片有稳定 ID，可独立设置或删除。

缺少 X 或 Y 时继续显示旧版 `graph.dragHint`。只读/保存锁定状态禁止添加、删除和修改设置。来源失效、字段缺失和不支持的 Y 类型维持当前诊断优先级。

Time Series 保留现有入口和时间轴解释能力，不因 X 是时间或时长而把普通 Line 自动改名或合并设置。已有 Time Series 兼容语义需在文档迁移中明确保留。

## Scatter 设置

| 设置 | 选项 | 默认值 |
| --- | --- | --- |
| Summary Statistic | None / Mean / Median / Sum | None |
| Error Interval | Auto / None / Standard Error / Standard Deviation / 95% CI | Auto |
| Interval Style | Error Bar / Band | Error Bar |
| Jitter | Stacked / Uniform / Normal | Stacked |
| Jitter Limit | 0–1，步长 0.01 | 0.5 |

None 显示原始观测值；其他汇总按 X 和 Overlay 分组显示一个汇总点。错误区间仅在汇总模式生效。抖动仅作用于原始点的水平显示位置，不改变原始数值、线图数据或统计结果。汇总模式保留抖动设置以便切回 None。

抖动使用稳定源行 ID、确定性种子和旧版模式算法；相同数据和相同视图不会因重复渲染随机跳动。Jitter Limit 为 0 时不偏移；旧值 `auto` 归一为 Stacked。计算和显示偏移使用绘图区几何，遵守已有画面裁剪。

## Line 设置

| 设置 | 选项 | 默认值 |
| --- | --- | --- |
| Row order | 开 / 关 | 关 |
| Connection | Line / Step / Spline | Line |
| Summary Statistic | Mean / Median / Sum / None | Mean |
| Fill | None / To Zero / Between | None |
| Error Interval | 与 Scatter 一致 | Auto |
| Interval Style | Error Bar / Band | Error Bar |
| Missing Factors | Skip / Include | Skip |
| Missing Values | Connect Through / Break | Connect Through |

None 显示原始数据连接；其他模式按 X 和 Overlay 分组汇总后连接。Row order 在原始模式按源行顺序连接，关闭时按 X 排序，相同 X 按源行 ID 稳定排序；汇总模式保持按 X 排序，并保留 Row order 选择。

Line 为直线连接，Step 对齐旧版中点阶梯，Spline 为平滑曲线。各 Overlay 组单独生成路径，不跨组连接。

To Zero 使用线与 Y=0 之间的填充。Between 使用当前误差上下界之间的区间带，与旧版语义一致；没有有效汇总区间时不生成填充。填充、线和点维持现有图组颜色规则及正确的绘制层次。

Missing Factors 控制分类 X 缺失值和 Overlay 缺失分组的纳入：Skip 排除，Include 保留明确的缺失类别/分组。连续或时间轴上没有合法坐标的 X 不能伪造为 0。Missing Values 的 Break 保留 Y 缺失造成的断点，Connect Through 连接其两侧合法观测值；必须在过滤无效数值前保留断点信息。

## 统计语义

统计结果以完整来源的合法观测值为依据，不能使用 LOD 代表点计算。Scatter 和 Line 可以采用不同汇总统计、误差区间和缺失策略。

沿用旧版规则：Mean、Median、Sum 按每个 X/Overlay 组计算；样本标准差使用 n−1 分母；Standard Error 为标准差除以平方根 n；Auto 使用 Standard Error；95% CI 使用旧版的 1.96 × Standard Error。区间以选中的汇总值为中心。n<2 时区间宽度为 0，不产生虚假的区间图元。None 不生成区间。

汇总、误差区间、填充和曲线生成必须处理空组、单点、常量、极大/极小有限值和溢出情况。溢出或无法表达的结果不能进入 GPU 几何或绘图域。

## 图层状态与项目迁移

引入 v3 文档，使用有稳定 ID 的有序 `layers` 列表，每项有 `kind` 和类型化 `options`。Scatter、Line 各自保存上述全部设置。X/Y、Overlay、隐藏组、相机和数据来源仍属于图形级状态。运行时 transport ID 不进入项目文档。

前端 store 提供添加、删除和按 ID 更新图层的操作，维持现有脏标记、只读守卫和无变化不写入规则。序列化、项目校验和 Rust 项目读取必须同步接受 v3，并保留 v1/v2 读取能力。非法枚举、非法抖动幅度和重复图层 ID 返回明确诊断。

迁移遵循“保持原已保存图形”的规则：

- `rawMode=scatter` 转为原始 Scatter；`line` 转为原始 Line；`pointsLine` 转为原始 Scatter + 原始 Line。迁移的原始图层保持旧版新版实际渲染所使用的排序、缺失和无抖动行为，不强制套用新建图层默认值。
- `showMean=true` 转为额外的 Mean Line，关闭误差区间以保留现有均值叠加效果；`false` 不添加。已有原始 Line 与均值 Line 分别保留，不用一个设置覆盖两条路径。
- v1 补齐空 Overlay 状态；v2 原样保留 Overlay 及隐藏组。保留相机、来源、字段 ID 和文档 ID。
- 兼容迁移在内存中完成，打开项目不自行标脏或写回。用户下次正常保存时输出 v3。保存恢复测试覆盖旧项目可见结果及重复加载的确定性。

新建图形按旧版默认值创建，不额外加入均值线。迁移后的旧图形可以显示多个 Line 卡片，这些卡片后续使用同一设置模型。

## 渲染、缓存与相机

前后端请求使用同一类型化图层配置，Rust 验证配置并生成各层所需的原始点、路径、汇总、区间和填充。每帧统一提交各图层，坐标轴仍由当前 WebView 显示。

来源缓存按数据来源、generation、X/Y 和 Overlay 身份复用；派生几何缓存额外包含会影响结果的图层设置。独立图层可以共享相同分组统计，但不能复用不同排序或缺失规则的路径。Median 使用完整分组数据或有界的精确外存计算，不用抽样中位数替代。

源行顺序和缺失断点必须能从缓存重建。修改设置可以触发可取消的派生准备；不足以计算某项设置的缓存可以在设置变更阶段准备完整数据。随后拖动、缩放和相机恢复不得触发来源重扫。新配置未完成前保留上一完整帧，避免显示新控件与旧结果却声称已更新。

沿用现有 CPU/GPU/磁盘预算、取消和最新请求优先规则。预算不足时显示该配置无法完成的原因，不用近似结果冒充精确统计。所有图层数据变化仍受来源 generation 和请求身份保护。

图层变更通常保留用户相机。首次自动范围需覆盖合法汇总和区间；用户点击 Reset view 时使用当前图层的完整范围。点抖动不会改变数据域。切换 X/Y 或轴解释继续沿用当前相机重置策略。

## 模块边界

- 共用设置描述和表单编辑组件：从旧版提取 Scatter/Line 编辑器，旧版和新版复用选项、顺序、翻译及默认值，避免两份设置再次漂移。
- 前端图层契约、store 和迁移：负责配置校验、图层操作、文档恢复和保存；不承担统计计算。
- Rust 图层计算模块：负责完整数据分组、统计、缺失处理和路径生成；独立测试算法及几何。
- 原生 renderer：接收受预算限制的几何，绘制点、线、区间和填充；不读取 UI 状态。
- GraphNewCanvas：负责帧呈现和相机生命周期，保持当前可读坐标轴、取消和重试规则。
